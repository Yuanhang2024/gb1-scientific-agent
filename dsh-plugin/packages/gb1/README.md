# GB1科学Agent · DSH插件

在DSH左侧打开“蛋白质进化”，点击顶部“一键准备并运行”，自动准备项目环境与GB1官方S1，训练预测器并按推荐配置运行。版本0.5同时保留自定义轮数、数据种子、候选数、推荐数量、模型思考强度、预算、上下文及预测器设置，支持独立重复与批量比较。

## 使用范围

- Windows、DSH `0.2.2-rc.1`，配合本项目Python环境。
- 数据采用Wu等人的GB1四位点S1实测及校准数据，可变位置为39、40、41、54。
- 参考序列必须与数据对应：

```text
MQYKLILNGKTLKGETTTEAVDAATAEKVFKQYANDNGVDGEWTYDDATKTFTVTE
```

- 语言模型提出候选，本地回归模型评分；选定推荐后才查询这些序列的实测值。
- 推荐方式包括随机、仅预测模型、基础Agent和知识辅助Agent。随机与仅模型方式不调用LLM。
- 同一运行内的数据划分、模型设置和提示版本保持固定；每条轨迹只使用自己的反馈。

## 一键准备并运行

推荐模型为GPT-6.1 Sol / xhigh，采用知识辅助v3、每轮40个候选和10条推荐、3轮、总计最多6次生成请求。顶部入口先检查模型能力，再检查或创建项目Python环境、安装固定依赖、下载并校验官方S1，随后进入原训练与反馈流程。已经有效的环境与数据直接复用。

一键操作不改已保存连接，也不读取下方未保存的手动参数。支持实际阶段显示、取消和同操作编号恢复；刷新不会再次提交。需要其他模型或档位时在卡片内明确选择。首次没有模型连接时，先在DSH配置一次可用模型。

完整准备流程、PowerShell 7备用入口及环境前提见[一键启动说明](<../../../一键启动.md>)。GUI入口不依赖系统PowerShell版本。

## 单次实验

1. 打开“实验设置”，选择推荐方式。
2. 使用Agent时选择模型连接和思考强度。
3. 输入轮数、数据随机种子、每轮候选数C和推荐数k。C与评分上限联动，必须满足`k <= C`。
4. 根据需要调整高级设置；开始前查看本次请求和实测查询预算。
5. 点击“开始实验”。在“工作对话”中查看真实工具步骤，在“推荐结果”中查看序列、设计理由及预测与实测分数。

默认配置提供3轮、C=40、k=10、最多2次生成请求/轮。轮数可以输入其他正整数，数据种子支持有效uint32整数；候选池与预算仍须满足实验要求。每轮最多2次请求表示首次设计加一次纠正，不等于两轮实验。

输出token与请求超时默认留空，沿用模型输出额度且不设置项目级请求超时。每个模型支持的思考档位由DSH实际能力信息提供。

## 连接方式

### DSH注册模型

选择已注册提供方和模型，请求由DSH模型服务执行。插件使用本次运行保存的模型与参数，不修改DSH全局模型设置。

### 独立接口

填写OpenAI兼容接口的Base URL、Model ID和API Key。密钥由DSH凭据服务保存，项目设置仅保留引用；界面只返回是否已配置。更换地址需重新填写密钥，空白密钥表示保留已有值。

“保存连接”保存连接信息；“移除密钥”仅清除本插件独立接口的凭据。随机与仅模型实验跳过连接保存。运行进行中使用已保存的连接与配置。

## 基础与高级设置

| 设置 | 含义 |
| --- | --- |
| 轮数、种子、C/k | 反馈迭代长度、初始数据划分及每轮设计/测量规模 |
| 思考强度、温度 | 本次模型生成设置；留空沿用服务默认，实际支持以通道为准 |
| 输出token、请求超时 | 可选单次请求控制；留空表示不额外设置 |
| 最多请求数、token阈值、实测查询预算 | 控制一次独立运行的资源使用 |
| 目标fitness、无改善轮数、最小改善幅度 | 可选提前停止条件；记录实际完成轮数和停止原因 |
| 初始训练、验证、测试与候选池大小 | 建立新的互斥划分，不按fitness挑选样本 |
| 预测器类别与参数 | 在验证集上选择配置，后续按本组已知数据重训 |
| 高分/对比例子、反馈窗口 | 控制LLM看见的已知数据和最近几轮详细反馈 |
| 提示版本、知识文件 | 默认v3，支持已注册版本和项目configs目录内的规则文件 |
| 允许位点、替换氨基酸、突变数量 | 在GB1四个位点范围内进一步限制候选 |
| 超额候选策略 | `reject`拒绝超额批次；`first_n`只取原始顺序前N条，再检查资格和评分 |
| 纠正示例、必须填满候选 | 决定纠正阶段是否提供无标签示例，以及不足目标但达到k时是否继续 |
| 文本长度、模型文件保存 | 控制输出字段长度和预测器快照存储 |

总token阈值在发起新请求前检查，已发出的单次请求可能使累计用量超过阈值；用量未知且设有阈值时停止继续派发。实测预算在下一完整轮次前检查，不会为了填满展示而补造候选。

关闭预测器文件保存后，训练与评分照常执行，仍保存配置、训练ID、预测值和实测反馈，可按配置重建预测器。

## 批量比较

在“批量比较”中选择DSH模型及其支持的思考档位，输入数据种子列表、每个划分的独立重复次数、全局和每个提供方的并发数量。任务数量按目标设置、种子、方法与重复次数展开；页面显示请求及查询预算。

每次重复都有独立运行编号和输出目录，从初始已知数据开始。任务不会通过轮流修改全局模型连接来切换模型。批量结果可分别查看完成情况、推荐质量和模型用量。

三个连续轮次来自同一条反馈轨迹；重复次数用于建立新的轨迹，独立统计以轨迹为单位。

## 暂停、恢复与停止

- **暂停**：正在执行的轮次完成并保存反馈后停下。
- **恢复**：使用原配置和已有反馈继续后续轮次。
- **停止/取消**：终止本次请求与工作进程，保留已有记录。
- **批量暂停**：停止派发新任务，并请求正在运行的任务在轮次边界暂停。
- **重启后恢复批量**：继续未开始的队列项；状态未知的运行保留供检查，不自动重发模型请求。

相同操作编号的重复提交返回已有结果。旧历史仍可查看；无法确认的请求不因刷新页面而再次提交。

## 查看与导出

- 工作对话展示调度、模型公开的analysis和工具输入输出数量；内部reasoning不进入面板。
- 推荐结果按轮次分页，支持搜索、排序、完整序列及突变位置比较，可导出全部轮次CSV。
- 实验分析使用实际保存的轻量轮次指标；本次参数在历史记录中保留。
- 较早运行缺少过程消息时显示历史摘要。工作对话最多保留160条消息和512 KiB展示数据，达到限制时提示；实验数据与原始过程记录另行保存。
- 项目说明中的历史v1对照是既有实验事实，不随当前参数改变。

预测值与实测值分别展示。未完成结果保持缺失，不记为fitness=0。

## 默认配置

默认配置由Host统一提供，并允许用户重置或应用预设。独立的默认值校准按固定方案比较多个数据划分和重复运行；推荐值采用实际完成的验证结果。

可在项目配置目录提供工作台默认配置，Host读取完整实验设置、提示版本和可选推荐模型。CLI原有配置保留用于历史复现；工作台新运行会保存实际采用的完整配置。

## 安装与构建

项目根目录应包含GB1核心代码、配置、提示、固定依赖清单和tools/quick_start引导源码，并有可用的Python 3.12基解释器；S1数据和项目虚拟环境可由一键入口准备。开发构建使用Node.js 24和pnpm。在`dsh-plugin`目录运行：

```powershell
node scripts/build.mjs
node scripts/test.mjs
```

构建生成Host、浏览器模块及21个严格Remote接口。运行时DSH依赖由宿主提供；插件可通过本地`link:`包安装。安装到其他目录时，用插件设置中的`projectRoot`指定项目根目录。构建或安装后刷新当前DSH页面。

## 记录与隔离

连接引用、操作回执、批量队列及公开运行摘要保存在项目的`.dsh-gb1`目录；科研数据位于`results/dsh-plugin/<运行ID>`。运行文件不进入Git提交。

Host负责凭据和模型调用，Python通过受校验的JSON行协议处理科研流程。密钥、认证信息和独立接口地址不传入Python。配置变化需创建新运行；旧记录按照保存时的设置解释。
