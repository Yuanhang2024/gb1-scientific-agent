## 六项指标

| 指标 | 定义与汇总方式 |
| --- | --- |
| 平均fitness | 每次完整轨迹新增推荐的平均实测fitness，再对数据划分等权汇总。误差线为95%分层bootstrap区间。 |
| 每轨迹最高fitness均值 | 先取每条完整轨迹中新发现的最高fitness，再按划分等权取均值。 |
| 完成率 | 实际完整完成的轨迹数除以计划轨迹数，直接标注n/N。 |
| 轨迹耗时 | 完整轨迹墙钟耗时的中位数；包含进程、数据读取、逐轮重训与生成，不含一次性共享准备和等待并发名额的时间。 |
| 报告tokens | 完整轨迹输入和输出的合计中位数，缓存输入计入一次。单位为千tokens，未折算金额。 |
| 有效输出速度 | 每轨迹所有请求输出tokens总数除以完整生成耗时之和，再取组中位数；包含思考与等待时间。 |

质量的误差线以数据划分和独立轨迹为两层重采样单位，采用已核查的10,000次bootstrap结果。完成率直接显示计数；耗时、Token和速度为中位数。

## 失败与缺失

第一阶段234条轨迹中202条完整完成，32条未完成；11次用量缺失均不在完整完成的轨迹中，因此这些请求没有被当作0成本加入完整轨迹中位数。失败仍保留在完成率与全部调用用量记录中。

DeepSeek-off没有完整轨迹，质量与完整轨迹成本均为N/A。Sol-low完成5/9条，但至少一个预定数据划分没有完整结果，无法按所有划分等权计算质量，图中标为N/A*；已有5条轨迹的资源统计仍保留。

不同阶段使用新的数据划分与生成重复，同一模型的第一阶段数值与最终确认数值属于不同批次样本。完整方法和选择规则见[校准报告](<../默认配置校准报告.md>)。
